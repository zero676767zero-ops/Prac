Install Java SE Development Kit 8

Set environment variable:
JAVA_HOME = C:\Program Files\Java\jdk1.8.x


Install Apache NetBeans version 14
During install:
Make sure JDK 8 is selected


STEP 3: Download Tomcat
Apache Tomcat version 9

Extract to:
C:\apache-tomcat-9.0.xx

STEP 4: Add Tomcat in NetBeans
Open NetBeans
Tools → Servers
Add Server
Select: Apache Tomcat
Browse folder
Finish

STEP 5: Create Maven Web App
File → New Project
Java with Maven → Web Application

Fill:
Project Name: prac
Group ID: com.mycompany
Server: Tomcat 9
Java EE Version: Java EE 7 Web 



STEP 6: Update pom.xml
Add:
<packaging>war</packaging>

Dependency:
com.sun.xml.ws : jaxws-rt : 2.3.3

Plugin:
maven-war-plugin



IMP : 
<dependencies>
    <dependency>
        <groupId>javax</groupId>
        <artifactId>javaee-web-api</artifactId>
        <version>7.0</version>
        <scope>provided</scope>
    </dependency>

    <dependency>
        <groupId>com.sun.xml.ws</groupId>
        <artifactId>jaxws-rt</artifactId>
        <version>2.3.5</version>
    </dependency>
</dependencies>

Then:
Right click → Clean & Build


STEP 7: Create Web Service
Create class:
HelloService

import javax.jws.WebService
import javax.jws.WebMethod
import javax.jws.WebParam

@WebService(serviceName = "HelloService")
public class HelloServer{
    @WebMethod(operationName = "sayHello")
    public string sayHello(@WebParam(name = "name") String name) {
        return "Hello" + name + "!"
    }
}

STEP 8: Configure XML Files
web.xml → correct
sun-jaxws.xml → correct
No change needed

STEP 9: Run Project
Right click → Run


STEP 10: Check WSDL
Open browser:
http://localhost:8080/prac10/HelloService?wsdl
